# Online Resume Builder

A simple web app that lets you fill in your details and see a clean, professional resume build up beside the form. When you're done, print it or save it as a PDF.

**Live demo:** https://govardhangoud7.github.io/online-resume-builder/

## Features

- Form for name, email, phone, address, career objective, education, skills, projects and certifications
- Resume preview that updates when you click **Generate Resume**
- Placeholder text stays in place for any field you leave empty
- Line breaks from the form are kept in the resume
- **Print / Save as PDF** button that prints only the resume
- Responsive layout that works on desktop and mobile

## Technologies Used

- HTML5
- CSS3 (Flexbox, media queries, print styles)
- JavaScript (DOM manipulation)

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/GovardhanGoud7/online-resume-builder.git
   ```
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

No installation or build step is needed.

## How to Use

1. Fill in your details in the form on the left.
2. Click **Generate Resume** to see your resume on the right.
3. Click **Print / Save as PDF**, then choose "Save as PDF" as the destination.
